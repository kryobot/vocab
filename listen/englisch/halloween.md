# Gängige Halloween-Wörter, 5. Klasse

# Gruselgestalten
die Hexe = witch
der Geist, das Gespenst = ghost | das h spricht man nicht
das Skelett = skeleton
der Vampir = vampire
die Mumie = mummy | Achtung: mummy heißt auch „Mama“
der Werwolf = werewolf
die Vogelscheuche = scarecrow

# Tiere
die Fledermaus = bat | auch: der Schläger (beim Baseball)
die Spinne = spider
das Spinnennetz = spider web / spiderweb / cobweb
die schwarze Katze = black cat
die Eule = owl

# Kürbis, Hexen und Zauberei
der Kürbis = pumpkin
die Kürbislaterne = jack-o'-lantern | ausgehöhlter Kürbis mit Gesicht und Kerze
die Kerze = candle
der Hexenbesen = broomstick / broom
der Hexenkessel = cauldron
der Zauberstab = wand / magic wand
der Zaubertrank = potion / magic potion
der Zauberspruch = spell
die Maske = mask
das Kostüm = costume

# Gruselorte
das Spukhaus = haunted house
der Friedhof = graveyard / cemetery
der Grabstein = gravestone / tombstone
der Sarg = coffin
der Totenkopf, der Schädel = skull
der Vollmond = full moon | der Mond = moon

# Halloween feiern
Fröhliches Halloween! = Happy Halloween!
sich verkleiden = to dress up | Ich verkleide mich als Hexe. = I dress up as a witch.
einen Kürbis schnitzen = to carve a pumpkin
die Süßigkeiten = sweets | amerikanisch: candy
Süßes oder Saures! = Trick or treat!
an Halloween Süßes sammeln gehen = to go trick-or-treating | von Haustür zu Haustür
der Herbst = autumn | amerikanisch: fall

# Gruseln
gruselig = scary / spooky / creepy
dunkel = dark
Angst haben = to be scared / to be afraid | Ich habe Angst. = I'm scared.
jemanden erschrecken = to scare / to frighten
schreien = to scream | laut rufen = to shout
Buh! = Boo!
