# Fortsetzung des spanischen Grundwortschatzes (Erklärung in Teil 1).

das Licht = la luz | Plural: las luces · apagar la luz = Licht ausmachen
das Feuer = el fuego | ¿tienes fuego? = hast du Feuer?
die Luft = el aire | al aire libre = im Freien
die Sonne = el sol | hace sol = die Sonne scheint
der Mond = la luna
der Stern = la estrella
der Himmel = el cielo | auch: der Himmel (religiös)
die Erde / das Land = la tierra | la Tierra = die Erde (Planet)
der Regen = la lluvia | llover = regnen · está lloviendo
der Schnee = la nieve | nevar = schneien
der Wind = el viento | hace viento = es ist windig
der Baum = el árbol
die Blume = la flor | Plural: las flores
das Tier = el animal
der Hund = el perro
die Katze = el gato | la gata = die Katze (weiblich)
das Pferd = el caballo | caballero = Herr, Ritter
der Vogel = el pájaro | allgemein: el ave
die Tatsache / die Tat = el hecho | de hecho = tatsächlich · hecho / hecha = gemacht
die Art / der Typ = el tipo | auch: der Kerl · el tipo de cambio = der Wechselkurs
die Mehrheit = la mayoría | la mayoría de la gente = die meisten Leute
das Zentrum / die Mitte = el centro | el centro de la ciudad = die Innenstadt
die Information = la información | Plural: las informaciones
der Prozess / der Vorgang = el proceso
die Handlung / die Aktion = la acción
die Beziehung = la relación
die Situation / die Lage = la situación
das Programm / die Sendung = el programa | männlich trotz -a
das Thema = el tema | männlich trotz -a
der Sinn / die Richtung = el sentido | sentido común = gesunder Menschenverstand
die Bedingung / der Zustand = la condición
der Präsident = el presidente | la presidenta
das Werk / die Baustelle = la obra | obra de teatro = Theaterstück
das Papier / die Rolle = el papel | papel higiénico = Klopapier · jugar un papel = eine Rolle spielen
die Angabe / die Daten = el dato | los datos = die Daten
das Mittel / die Mitte = el medio | los medios = die Medien · en medio de = mitten in
das Interesse = el interés | Plural: los intereses
das Ergebnis = el resultado
der Bereich / die Fläche = el área | weiblich: las áreas (el wegen betontem a-)
die Basis / die Grundlage = la base | a base de = auf Grundlage von
der Wert / der Mut = el valor
die Ordnung / der Befehl = el orden / la orden | el orden = Ordnung, Reihenfolge · la orden = Befehl
der Raum / der Platz (Weltraum) = el espacio
die Kultur = la cultura
die Freiheit = la libertad
der Frieden = la paz | ¡déjame en paz! = lass mich in Ruhe!
das Recht / rechts = el derecho | a la derecha = rechts · derecho / derecha = gerade, recht
links = a la izquierda | izquierdo / izquierda = linker, linke
geradeaus = todo recto | LatAm: derecho
die Kraft / die Gewalt = la fuerza | a la fuerza = gezwungenermaßen
die Möglichkeit = la posibilidad
die Notwendigkeit / das Bedürfnis = la necesidad
die Gesundheit = la salud | ¡salud! = Prost! / Gesundheit!
die Bildung / die Erziehung = la educación | falscher Freund: auch Höflichkeit (bien educado = höflich)
die Tätigkeit / die Aktivität = la actividad
die Erfahrung = la experiencia
das Wissen / die Kenntnis = el conocimiento
die Sprache = el idioma | männlich trotz -a · auch: la lengua (= auch die Zunge)
die Maßnahme / das Maß = la medida | a medida que = je nachdem wie
der Gegenstand / das Ziel = el objeto | el objetivo = das Ziel
der Erfolg = el éxito | falscher Freund: nicht „Exit“ – der Ausgang heißt la salida
der Fehler = el error | auch: la falta (Rechtschreibfehler)
die Angst = el miedo | männlich · dar miedo = Angst machen
das Glück (Zufall) = la suerte | ¡buena suerte! · tener suerte = Glück haben
das Vergnügen / der Geschmack = el gusto | mucho gusto = sehr erfreut
der Traum / der Schlaf = el sueño | tener sueño = müde sein
die Vorsicht / die Pflege = el cuidado | ¡cuidado! = Vorsicht!
die Schuld = la culpa | es mi culpa = es ist meine Schuld
die Eile = la prisa | tengo prisa = ich habe es eilig
der Hunger = el hambre | weiblich: tengo mucha hambre
der Durst = la sed | tengo sed = ich habe Durst
der Schmerz = el dolor | me duele la cabeza = mir tut der Kopf weh
die Stimme = la voz | Plural: las voces · en voz alta = laut
die Stille = el silencio | ¡silencio! = Ruhe!
der Lärm / das Geräusch = el ruido
die Nachricht (Neuigkeit) = la noticia | las noticias = die Nachrichten (TV)
die Zeitung = el periódico
der Brief = la carta | auch: die Speisekarte, die Spielkarte
die Nachricht (Mitteilung) = el mensaje | mandar un mensaje = eine Nachricht schicken
das Telefon / das Handy = el teléfono | Handy: el móvil · LatAm: el celular
der Computer = el ordenador | LatAm: la computadora
der Film = la película | ver una película = einen Film schauen
das Foto = la foto | weiblich (von la fotografía)
der Fernseher / das Fernsehen = la televisión | kurz: la tele
der Preis (Kosten) = el precio | Auszeichnung = el premio
kosten = costar | cuesta · ¿cuánto cuesta? = was kostet das?
ausgeben (Geld) = gastar | los gastos = die Ausgaben
sparen = ahorrar
leihen (verleihen) = prestar | ¿me prestas …? = leihst du mir …?
mieten = alquilar | el alquiler = die Miete
zurückgeben = devolver | devuelvo · Partizip: devuelto
übergeben / abgeben = entregar
aufbewahren / speichern = guardar | guardar silencio = schweigen
hineinstecken / hineintun = meter | meter la pata = ins Fettnäpfchen treten
werfen / hinauswerfen = echar | echar de menos = vermissen
fehlen = faltar | me falta tiempo = mir fehlt Zeit
übrig sein = sobrar
wert sein / gelten = valer | vale = okay (Spanien) · no vale la pena = es lohnt sich nicht
wichtig sein / ausmachen = importar | no importa = macht nichts
wehtun = doler | me duele = es tut mir weh
