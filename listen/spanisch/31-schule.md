die Schule = la escuela | auch: el colegio (Spanien)
die Klasse / der Unterricht = la clase | dar clase = unterrichten
der Lehrer = el profesor | la profesora = die Lehrerin · Grundschule auch: el maestro / la maestra
der Schüler / der Student = el estudiante | la estudiante · Schüler auch: el alumno / la alumna
lernen = aprender | aprender a nadar = schwimmen lernen
studieren / lernen (für die Schule) = estudiar
unterrichten / beibringen = enseñar | enseñar a leer = lesen beibringen · auch: zeigen
die Prüfung (Examen) = el examen | aprobar = bestehen · suspender = durchfallen
die Note / die Notiz = la nota | sacar buenas notas = gute Noten bekommen
die Lektion / die Lehre = la lección
korrigieren = corregir | corrijo
der Fehler = el error | auch: la falta (Rechtschreibfehler)
der Erfolg = el éxito | falscher Freund: nicht „Exit“ – der Ausgang heißt la salida
die Bildung / die Erziehung = la educación | falscher Freund: auch Höflichkeit (bien educado = höflich)
die Karriere / das Rennen / das Studium = la carrera | estudio la carrera de … = ich studiere …
die Regel / das Lineal = la regla | por regla general = in der Regel
der Kollege / der Mitschüler = el compañero | la compañera · compañero de piso = Mitbewohner
wiederholen = repetir | repito · ¿puede repetir? = können Sie das wiederholen?
der Beweis / die Prüfung (Test) = la prueba | probar = probieren, testen
die Anstrengung = el esfuerzo
