# Fortsetzung des spanischen Grundwortschatzes (Erklärung in Teil 1).

lang = largo / larga | falscher Freund: largo heißt nicht „large“
bekommen / empfangen = recibir | recibir una carta = einen Brief bekommen
sich erinnern = recordar | recuerdo · auch: acordarse de
beenden / fertig werden = terminar | ¿terminaste? = bist du fertig?
erreichen / schaffen / besorgen = conseguir | consigo, consigues …
lesen = leer | Vergangenheit: leyó, leyeron
ändern / wechseln = cambiar | cambiar de idea = es sich anders überlegen · el cambio = die Änderung, das Wechselgeld
öffnen = abrir | Partizip: abierto
hören = oír | oigo, oyes, oye … · ¡oye! = hör mal!
helfen = ayudar | ayudar a alguien = jemandem helfen · la ayuda = die Hilfe
spielen = jugar | juego, juegas … · jugar al fútbol · Instrument spielen = tocar
zeigen = mostrar | muestro · auch: enseñar
gewinnen / verdienen = ganar | ganar dinero = Geld verdienen
bringen / mitbringen = traer | traigo, traes … · Vergangenheit: traje
sterben = morir | muero · Partizip: muerto
annehmen / akzeptieren = aceptar
erklären = explicar | expliqué = ich erklärte
lernen = aprender | aprender a nadar = schwimmen lernen
studieren / lernen (für die Schule) = estudiar
benutzen = usar | auch: utilizar
schließen = cerrar | cierro · cerrado = geschlossen
zuhören / hören (bewusst) = escuchar | ¡escucha! = hör zu!
fragen = preguntar | la pregunta = die Frage
antworten = contestar | auch: responder · la respuesta = die Antwort
sich setzen = sentarse | me siento · ¡siéntate! = setz dich!
schlafen = dormir | duermo · dormirse = einschlafen
rennen / laufen = correr
gehen (zu Fuß) = caminar | in Spanien oft: andar
kaufen = comprar | ir de compras = einkaufen gehen
bezahlen = pagar | pagué = ich bezahlte
verkaufen = vender
hinaufgehen / steigen = subir | subir al autobús = in den Bus einsteigen
hinuntergehen / senken = bajar | bajar del tren = aus dem Zug aussteigen
reisen = viajar | el viaje = die Reise
geschehen / vorkommen = ocurrir | auch: suceder
existieren = existir
erlauben = permitir | ¿me permite? = darf ich?
erscheinen / auftauchen = aparecer | aparezco
schaffen / erschaffen = crear
herstellen / produzieren = producir | produzco · Vergangenheit: produjo
vorstellen / präsentieren = presentar | te presento a Ana = darf ich dir Ana vorstellen
halten für / betrachten = considerar
sich herausstellen / ergeben = resultar | resulta que … = es stellt sich heraus, dass …
halten / aufrechterhalten = mantener | mantengo (wie tener)
dienen / servieren = servir | sirvo · ¿para qué sirve? = wozu ist das gut?
herausnehmen / holen = sacar | sacar una foto = ein Foto machen
fallen = caer | caigo · caerse = hinfallen
gerade getan haben / beenden = acabar | acabo de llegar = ich bin gerade angekommen
sich verwandeln / werden = convertirse | convertirse en = sich verwandeln in, werden zu
bilden / formen = formar | formar parte de = Teil sein von
erreichen / schaffen (Ziel) = lograr | lograr + Infinitiv = es schaffen zu
verwirklichen / durchführen = realizar | falscher Freund: nicht „realisieren“ (= darse cuenta)
annehmen / vermuten = suponer | supongo · por supuesto = selbstverständlich
entwickeln = desarrollar | el desarrollo = die Entwicklung
anbieten = ofrecer | ofrezco
versuchen (probieren) = intentar | el intento = der Versuch
vergessen = olvidar | olvidarse de = vergessen
vorziehen / lieber mögen = preferir | prefiero
entscheiden = decidir | la decisión = die Entscheidung
wählen / aussuchen = elegir | elijo, eliges …
schicken = enviar | auch: mandar
der Körper = el cuerpo
der Kopf = la cabeza | dolor de cabeza = Kopfschmerzen
das Auge = el ojo | ¡ojo! = Achtung! Pass auf!
das Gesicht = la cara | nicht verwechseln: caro / cara = teuer
das Herz = el corazón
die Tür = la puerta | la puerta de casa = die Haustür
die Straße = la calle | Hausnummer: calle Mayor, 5
das Auto = el coche | LatAm: el carro / el auto
das Buch = el libro | falscher Freund: la librería = Buchhandlung
das Geld = el dinero
die Rechnung / das Konto = la cuenta | darse cuenta = merken, bemerken
die Idee = la idea | ni idea = keine Ahnung
der Grund / die Vernunft = la razón | tener razón = recht haben
der Krieg = la guerra
der Tod = la muerte
die Liebe = el amor | mi amor = mein Schatz
das Ende / das Ziel = el fin | por fin = endlich · el fin de semana = das Wochenende
das Finale / der Schluss = el final | al final = am Ende
die Seite (Richtung) = el lado | al lado de = neben
die Gruppe = el grupo
die Firma / das Unternehmen = la empresa
die Regierung = el gobierno
das Gesetz = la ley | Plural: las leyes
der Staat / der Zustand = el estado | los Estados Unidos = die USA
das System = el sistema | männlich trotz -a
der Dienst / die Toilette = el servicio | ¿dónde están los servicios? = wo sind die Toiletten?
die Ebene / das Niveau = el nivel
die Nummer / die Zahl = el número
der Tisch = la mesa | poner la mesa = den Tisch decken
das Zimmer = la habitación | auch: el cuarto
die Schule = la escuela | auch: el colegio (Spanien)
die Klasse / der Unterricht = la clase | dar clase = unterrichten
der Lehrer = el profesor | la profesora = die Lehrerin · Grundschule auch: el maestro / la maestra
der Schüler / der Student = el estudiante | la estudiante · Schüler auch: el alumno / la alumna
die Musik = la música
das Spiel = el juego | el partido = das (Sport-)Spiel
das Essen / die Mahlzeit = la comida | auch: das Mittagessen (Spanien)
das Brot = el pan | Plural: los panes
der Kaffee / das Café = el café | café con leche = Milchkaffee
