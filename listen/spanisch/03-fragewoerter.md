# Spanischer Grundwortschatz nach Themen – Liste 3 von 39.
# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

was? / welche? = qué | ¡qué bonito! = wie schön!
wie? = cómo | ¿cómo estás? = wie geht’s dir?
wo? = dónde | ¿de dónde eres? = woher kommst du?
wer? = quién | Plural: quiénes
welcher? / welche? = cuál | ¿cuál es tu nombre? · Plural: cuáles
wie viel? = cuánto / cuánta | ¿cuánto cuesta? = was kostet das?
wann? = cuándo | ¿cuándo empieza? = wann fängt es an?
warum? = por qué | Antwort: porque … = weil …
wohin? = adónde | ¿adónde vas? = wohin gehst du?
dieser / diese = este / esta | Neutrum: esto = das hier
der da / die da (beim Gegenüber) = ese / esa | Neutrum: eso
jener / jene (weit weg) = aquel / aquella | Neutrum: aquello · en aquel tiempo = damals
das (da) = eso | ¡eso es! = genau! · por eso = deshalb
hier = aquí | LatAm oft: acá
da (beim Gegenüber) = ahí | ahí está = da ist er/sie/es
dort = allí | LatAm oft: allá · ahí = da (näher)
so / auf diese Weise = así | así que = also, deshalb
so (vor Adjektiv) = tan | tan grande como = so groß wie
so viel = tanto / tanta | por lo tanto = deshalb
solch / so ein = tal | ¿qué tal? = wie geht’s? · tal vez = vielleicht
