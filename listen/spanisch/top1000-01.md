# Spanischer Grundwortschatz: die 1000 häufigsten/wichtigsten Wörter,
# zusammengestellt aus der Häufigkeitsliste von Mark Davies („A Frequency
# Dictionary of Spanish“ – Grundlage der gängigen Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), einer Häufigkeitsliste aus Film-Untertiteln
# (OpenSubtitles, für gesprochene Alltagssprache) und gängigen Grundwortschatz-
# listen. Reihenfolge = Wichtigkeit, Teil 1 enthält deshalb viele kleine Wörter.
#
# Rückseite: Spanisch, Nomen mit Artikel (el = männlich, la = weiblich),
# Adjektive als männliche / weibliche Form. Hinweis: Besonderheiten,
# unregelmäßige Formen, kurze Beispiele. Grundlage ist Spanien-Spanisch,
# lateinamerikanische Varianten stehen im Hinweis (LatAm: …).

der (bestimmter Artikel, männlich) = el | Plural: los · el libro, los libros
die (bestimmter Artikel, weiblich) = la | Plural: las · auch „sie“ als Objekt: la veo = ich sehe sie
von / aus (Herkunft, Besitz) = de | de + el = del · el libro de Ana = Anas Buch
dass / der, die, das (Relativpronomen) = que | ohne Akzent · mit Akzent: qué = was?
und = y | vor i-/hi- wird y zu e: padre e hijo
zu / nach / an (Richtung) = a | a + el = al · vor Personen als Objekt: veo a Juan
in / auf / an (Ort) = en | en casa = zu Hause · en la mesa = auf dem Tisch
ein / eine = un / una | Plural unos / unas = einige
sein (Wesen, Identität, Herkunft) = ser | soy, eres, es, somos, sois, son · ser = was etwas ist, estar = wie/wo es ist
sich = se | auch „man“: aquí se habla español = hier spricht man Spanisch
nein / nicht = no | no sé = ich weiß nicht
haben (Hilfsverb) / es gibt = haber | he, has, ha, hemos, habéis, han · hay = es gibt
durch / wegen / für (Grund, Tausch) = por | por = Ursache, Weg, Tausch · para = Zweck, Ziel
mit = con | conmigo = mit mir · contigo = mit dir
sein / ihr / Ihr (Possessiv) = su | Plural: sus · gilt für él, ella, usted, ellos, ellas
für / um zu (Zweck, Ziel) = para | para ti = für dich · para aprender = um zu lernen
wie (Vergleich) / als = como | ohne Akzent · cómo = wie? (Frage)
sein (Zustand, Ort) = estar | estoy, estás, está, estamos, estáis, están · estoy cansada = ich bin müde
haben (besitzen) = tener | tengo, tienes, tiene … · tener que = müssen · tengo 30 años = ich bin 30
ihm / ihr (indirektes Objekt) = le | Plural: les · le doy el libro = ich gebe ihm/ihr das Buch
ihn / es (direktes Objekt) = lo | lo bueno = das Gute · lo sé = ich weiß es
alles / ganz = todo | todo el día = den ganzen Tag · todos = alle
aber = pero
mehr = más | mit Akzent · más o menos = mehr oder weniger
machen / tun = hacer | hago, haces, hace … · Partizip: hecho · hace frío = es ist kalt
oder = o | vor o-/ho- wird o zu u: siete u ocho
können = poder | puedo, puedes, puede, podemos … · el poder = die Macht
sagen = decir | digo, dices, dice … · Partizip: dicho
dieser / diese = este / esta | Neutrum: esto = das hier
gehen / fahren = ir | voy, vas, va, vamos, vais, van · ir a + Infinitiv = etwas tun werden
anderer / noch ein = otro / otra | ohne „un“: otro café = noch ein Kaffee
der da / die da (beim Gegenüber) = ese / esa | Neutrum: eso
wenn / ob = si | ohne Akzent · sí = ja
mich / mir = me | me llamo … = ich heiße …
schon / bereits = ya | ya no = nicht mehr
sehen = ver | veo, ves, ve … · Partizip: visto
weil = porque | ¿por qué? = warum?
geben = dar | doy, das, da … · Vergangenheit: di, diste, dio
wenn / als (zeitlich) = cuando | ¿cuándo? = wann?
er = él | mit Akzent · el ohne Akzent = der
sehr = muy | muy bien = sehr gut · aber: mucho = viel
ohne = sin | sin azúcar = ohne Zucker
das Mal = la vez | Plural: las veces · a veces = manchmal · otra vez = noch einmal
viel = mucho / mucha | muchas gracias = vielen Dank
wissen = saber | sé, sabes, sabe … · sé nadar = ich kann schwimmen (gelernt)
was? / welche? = qué | ¡qué bonito! = wie schön!
über / auf = sobre | sobre la mesa = auf dem Tisch · hablar sobre = sprechen über
mein / meine = mi | Plural: mis · mí mit Akzent nach Präposition: para mí
irgendein / einige = alguno / alguna | vor männl. Nomen: algún día = eines Tages
derselbe / selbst = mismo / misma | lo mismo = dasselbe · yo misma = ich selbst
ich = yo
auch = también | tampoco = auch nicht
bis = hasta | ¡hasta luego! = bis später
das Jahr = el año | ñ wie „nj“ · ¿cuántos años tienes? = wie alt bist du?
zwei = dos
wollen / lieben = querer | quiero, quieres, quiere … · te quiero = ich hab dich lieb
zwischen / unter = entre | entre amigos = unter Freunden
so / auf diese Weise = así | así que = also, deshalb
erster / zuerst = primero / primera | vor männl. Nomen: el primer día
seit / von … aus = desde | desde hace dos años = seit zwei Jahren
groß = grande | vor Nomen kurz gran = großartig: un gran día
das (da) = eso | ¡eso es! = genau! · por eso = deshalb
weder … noch / nicht einmal = ni | ni idea = keine Ahnung
uns = nos | nos vemos = wir sehen uns
ankommen = llegar | llegué = ich kam an · llegar a ser = werden
passieren / verbringen / vorbeigehen = pasar | ¿qué pasa? = was ist los?
die Zeit / das Wetter = el tiempo | hace buen tiempo = das Wetter ist gut · Uhrzeit = la hora
sie (Singular) = ella | Plural: ellas
ja = sí | mit Akzent · si ohne Akzent = wenn/ob
der Tag = el día | männlich trotz -a · buenos días = guten Morgen
eins (Zahl) = uno | vor männl. Nomen: un libro
gut (Adverb) = bien | estoy bien = mir geht’s gut · Adjektiv: bueno
wenig = poco / poca | un poco = ein bisschen
müssen / sollen / schulden = deber | debes descansar = du solltest dich ausruhen · el deber = die Pflicht
dann / also = entonces
setzen / stellen / legen = poner | pongo, pones … · Partizip: puesto · ponerse = anziehen; werden
die Sache / das Ding = la cosa
so viel = tanto / tanta | por lo tanto = deshalb
der Mann / der Mensch = el hombre | h ist stumm · ¡hombre! = Mensch! (Ausruf)
scheinen / aussehen wie = parecer | parezco · me parece bien = finde ich gut
unser / unsere = nuestro / nuestra
so (vor Adjektiv) = tan | tan grande como = so groß wie
wo = donde | ¿dónde? (Frage) mit Akzent
jetzt = ahora | ahora mismo = sofort
der Teil = la parte | weiblich · en todas partes = überall
danach / nachher = después | después de comer = nach dem Essen
das Leben = la vida
bleiben / sich verabreden = quedar | quedarse = bleiben · quedamos a las 8 = wir treffen uns um 8
immer = siempre
glauben = creer | creo que sí = ich glaube schon
sprechen / reden = hablar | h ist stumm
tragen / mitnehmen = llevar | llevo dos años aquí = ich bin seit zwei Jahren hier
lassen / verlassen = dejar | dejar de fumar = aufhören zu rauchen
nichts = nada | de nada = gern geschehen
jeder / jede (einzeln) = cada | unveränderlich: cada día = jeden Tag
folgen / weitermachen = seguir | sigo, sigues … · sigue lloviendo = es regnet weiter
weniger = menos | las tres menos cuarto = Viertel vor drei
neu = nuevo / nueva | de nuevo = noch einmal
finden / treffen = encontrar | encuentro · encontrarse con = jemanden treffen
etwas = algo | ¿algo más? = sonst noch etwas?
