# Fortsetzung des spanischen Grundwortschatzes (Erklärung in Teil 1).

du = tú | mit Akzent · tu ohne Akzent = dein
Sie (Höflichkeitsform) = usted | Abkürzung Ud. · Verb in der 3. Person: ¿cómo está usted?
wir = nosotros / nosotras
sie (Plural) = ellos / ellas | ellos = männlich oder gemischt
dich / dir = te | te llamo = ich rufe dich an
hallo = hola | h ist stumm
danke = gracias | muchas gracias = vielen Dank · gracias por todo = danke für alles
bitte (Bitte) = por favor | „bitte schön“ beim Überreichen: aquí tiene / toma
tschüss / auf Wiedersehen = adiós
gut (Adjektiv) = bueno / buena | vor männl. Nomen: buen día · bueno … = na gut …
hier = aquí | LatAm oft: acá
besser = mejor | lo mejor = das Beste
nie = nunca | nunca jamás = nie im Leben
vorher / bevor = antes | antes de salir = bevor ich gehe
das Haus / das Zuhause = la casa | en casa = zu Hause · a casa = nach Hause
die Frau = la mujer | auch: Ehefrau · Plural: las mujeres
die Welt = el mundo | todo el mundo = alle (Leute)
der Ort / der Platz = el lugar | en lugar de = anstatt
der Moment / der Augenblick = el momento | en este momento = gerade
rufen / anrufen / heißen = llamar | me llamo Lotte = ich heiße Lotte
kommen = venir | vengo, vienes, viene … · ¡ven! = komm!
denken = pensar | pienso, piensas … · pensar en = denken an
hinausgehen / ausgehen / abfahren = salir | salgo, sales … · la salida = der Ausgang
zurückkommen = volver | vuelvo · volver a + Infinitiv = etwas wieder tun
nehmen / trinken = tomar | tomar un café = einen Kaffee trinken · tomar el tren = den Zug nehmen
kennen / kennenlernen = conocer | conozco, conoces … · Leute/Orte kennen, Fakten wissen = saber
leben / wohnen = vivir | vivo en Berlín = ich wohne in Berlin
fühlen / bedauern = sentir | siento, sientes … · lo siento = es tut mir leid
versuchen / behandeln = tratar | tratar de + Infinitiv = versuchen zu · se trata de = es geht um
schauen / ansehen = mirar | ¡mira! = schau mal!
erzählen / zählen = contar | cuento · contar con = sich verlassen auf
anfangen = empezar | empiezo, empiezas …
warten / hoffen = esperar | espero que sí = ich hoffe es
suchen = buscar | busqué = ich suchte
hereinkommen / eintreten = entrar | entrar en / a = hineingehen in · la entrada = der Eingang
arbeiten = trabajar
schreiben = escribir | Partizip: escrito
verlieren / verpassen = perder | pierdo · perder el tren = den Zug verpassen
verstehen = entender | entiendo, entiendes …
bitten / bestellen = pedir | pido, pides … · pedir la cuenta = die Rechnung verlangen
gefallen / mögen = gustar | me gusta el café = ich mag Kaffee · me gustan los libros (Plural!)
brauchen = necesitar
nur / allein = solo / sola | nur = solo (Adverb, früher sólo) · allein = solo/sola
wie? = cómo | ¿cómo estás? = wie geht’s dir?
wo? = dónde | ¿de dónde eres? = woher kommst du?
wer? = quién | Plural: quiénes
welcher? / welche? = cuál | ¿cuál es tu nombre? · Plural: cuáles
wie viel? = cuánto / cuánta | ¿cuánto cuesta? = was kostet das?
heute = hoy | hoy en día = heutzutage
morgen / der Morgen = mañana | morgen = mañana · der Morgen = la mañana · pasado mañana = übermorgen
gestern = ayer | anteayer = vorgestern
später / dann = luego | ¡hasta luego! = bis später
noch (immer) = todavía | todavía no = noch nicht · auch: aún
fast = casi | casi nunca = fast nie
obwohl = aunque | aunque llueva = auch wenn es regnet
während (Konjunktion) = mientras | mientras tanto = inzwischen
während (Präposition) = durante | durante el día = tagsüber
gegen = contra | estar en contra = dagegen sein
in Richtung / gegen (zeitlich) = hacia | hacia las cinco = gegen fünf Uhr
sondern = sino | no es rojo sino azul
deshalb = por eso | auch: por lo tanto, así que
solch / so ein = tal | ¿qué tal? = wie geht’s? · tal vez = vielleicht
das Land = el país | Plural: los países
die Leute = la gente | grammatisch Singular: la gente dice …
die Person = la persona | immer weiblich, auch für Männer
die Arbeit = el trabajo | auch: der Job, die Stelle
die Stunde / die Uhrzeit = la hora | ¿qué hora es? = wie spät ist es?
die Hand = la mano | weiblich trotz -o!
der Fall = el caso | en ese caso = in dem Fall · en todo caso = jedenfalls
die Form / die Art = la forma | de todas formas = jedenfalls
das Beispiel = el ejemplo | por ejemplo = zum Beispiel
die Art und Weise = la manera | de esta manera = auf diese Weise
der Punkt = el punto | en punto = pünktlich (a las tres en punto)
das Wasser = el agua | weiblich, aber el wegen betontem a- · el agua fría
essen = comer | la comida = das Essen
trinken = beber | im Alltag oft auch: tomar
der Sohn = el hijo | los hijos = die Kinder (eigene)
die Tochter = la hija
der Vater = el padre | los padres = die Eltern · Kindersprache: papá
die Mutter = la madre | Kindersprache: mamá
die Familie = la familia
der Freund (Kumpel) = el amigo | la amiga = die Freundin · fester Freund = el novio
das Kind = el niño | la niña = das Mädchen · los niños = die Kinder
der Name = el nombre | el apellido = der Nachname
die Stadt = la ciudad | Plural: las ciudades
die Nacht = la noche | buenas noches = gute Nacht · esta noche = heute Abend
die Woche = la semana | el fin de semana = das Wochenende
der Monat = el mes | Plural: los meses
das Wort = la palabra
die Geschichte = la historia | auch: das Schulfach Geschichte
das Problem = el problema | männlich trotz -a · no hay problema = kein Problem
die Wahrheit = la verdad | ¿verdad? = nicht wahr?
sicher / gewiss (wahr) = cierto / cierta | es cierto = das stimmt
klar / hell = claro / clara | ¡claro! = klar! natürlich!
sicher (zuversichtlich) = seguro / segura | auch: la seguridad = die Sicherheit
letzter / letzte = último / última | por último = zuletzt
älter / größer (Vergleich) = mayor | la mayoría = die Mehrheit · las personas mayores = ältere Menschen
klein = pequeño / pequeña | LatAm oft: chico
schlecht = malo / mala | vor männl. Nomen: mal tiempo · Adverb: mal
hoch / groß (Körpergröße) = alto / alta | ¡alto! = halt!
