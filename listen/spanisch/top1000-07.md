# Fortsetzung des spanischen Grundwortschatzes (Erklärung in Teil 1).

begeistern / sehr mögen = encantar | me encanta = ich liebe es
interessieren = interesar | me interesa = es interessiert mich
stören / ärgern = molestar | ¿te molesta? = stört es dich?
leiten / richten an = dirigir | dirijo · la dirección = die Adresse, die Richtung
besetzen / einnehmen = ocupar | ocupado / ocupada = besetzt, beschäftigt
festlegen / gründen = establecer | establezco
hinweisen / zeigen auf = señalar
angeben / anzeigen = indicar
darstellen / vertreten = representar
einschließen / beinhalten = incluir | incluyo · incluido = inklusive
abholen / aufsammeln = recoger | recojo · recoger a los niños = die Kinder abholen
beobachten = observar
sich vorstellen (denken) = imaginar | ¡imagínate! = stell dir vor!
träumen = soñar | sueño con … = ich träume von …
sich kümmern um / aufpassen auf = cuidar | cuidar a los niños = auf die Kinder aufpassen
töten = matar
gehen (spazieren) / laufen (Gerät) = andar | ando · Vergangenheit: anduve
Haupt- / wichtigste = principal | la calle principal = die Hauptstraße
aktuell / derzeitig = actual | falscher Freund: nicht „tatsächlich“ (= real, de hecho)
menschlich = humano / humana | el ser humano = der Mensch
international = internacional
besonders / speziell = especial | especialmente = besonders (Adverb)
normal = normal
einfach (schlicht) = simple | auch: sencillo / sencilla
natürlich (naturgemäß) = natural | ¡es natural! = das ist normal
persönlich = personal | el personal = das Personal
jünger / kleiner (Vergleich) = menor | menor de edad = minderjährig
nächster (folgender) = siguiente | al día siguiente = am nächsten Tag
vorheriger = anterior | el año anterior = das Jahr davor
nächster / kommender = próximo / próxima | la próxima semana = nächste Woche
ernst = serio / seria | ¿en serio? = im Ernst?
ruhig = tranquilo / tranquila | ¡tranquilo! = keine Sorge, ruhig!
nervös = nervioso / nerviosa
zufrieden = contento / contenta | estoy contenta (mit estar)
besorgt = preocupado / preocupada
wütend / verärgert = enfadado / enfadada | LatAm: enojado / enojada
gelangweilt / langweilig = aburrido / aburrida | estar aburrido = gelangweilt · ser aburrido = langweilig
interessant = interesante
lustig / unterhaltsam = divertido / divertida | divertirse = Spaß haben
seltsam / selten = raro / rara
fremd / merkwürdig = extraño / extraña | extrañar = vermissen (v. a. LatAm), Spanien meist: echar de menos
perfekt = perfecto / perfecta
irgendein (beliebig) = cualquier | cualquier cosa = irgendwas · nach Nomen: cualquiera
mehrere / verschiedene = varios / varias
die übrigen / die anderen = los demás | lo demás = der Rest
beide = ambos / ambas | auch: los dos / las dos
zu (sehr) / zu viel = demasiado | demasiado caro = zu teuer
ziemlich / genug = bastante | bastante bien = ziemlich gut
genug / ausreichend = suficiente | ¡ya es suficiente! = jetzt reicht’s!
halb = medio / media | medio kilo = ein halbes Kilo · una hora y media
die Hälfte = la mitad | a mitad de precio = zum halben Preis
das Viertel = el cuarto | las dos y cuarto = Viertel nach zwei · auch: das Zimmer
die Haare = el pelo | Singular! · tengo el pelo largo = ich habe lange Haare
der Mund = la boca
die Nase = la nariz | Plural: las narices
das Ohr = la oreja | das Gehör / Innenohr = el oído
der Zahn = el diente | lavarse los dientes = Zähne putzen
der Arm = el brazo
das Bein = la pierna
der Fuß = el pie | a pie = zu Fuß
der Finger = el dedo | auch: der Zeh (dedo del pie)
der Rücken = la espalda
der Bauch / der Magen = el estómago | Bauch auch: la barriga, la tripa
das Blut = la sangre | weiblich
die Haut = la piel | auch: das Leder, das Fell
die Kleidung = la ropa | Singular! · ponerse la ropa = sich anziehen
das Hemd = la camisa | la camiseta = das T-Shirt
die Hose = el pantalón | meist Plural: los pantalones
das Kleid = el vestido
der Rock = la falda
der Schuh = el zapato | las zapatillas = Turnschuhe, Hausschuhe
die Jacke = la chaqueta | Mantel = el abrigo · LatAm: la chamarra
die Tasche / die Handtasche = el bolso | Hosentasche = el bolsillo · Tüte = la bolsa
weiß = blanco / blanca
schwarz = negro / negra
rot = rojo / roja
grün = verde | auch: unreif
blau = azul | Plural: azules
gelb = amarillo / amarilla
grau = gris
braun = marrón | Haare/Augen: castaño
rosa = rosa | unveränderlich: camisas rosa
die Farbe = el color | männlich · ¿de qué color es? = welche Farbe hat es?
Montag = el lunes | Wochentage klein und männlich · el lunes = am Montag
Dienstag = el martes
Mittwoch = el miércoles
Donnerstag = el jueves
Freitag = el viernes
Samstag = el sábado
Sonntag = el domingo
der Frühling = la primavera
der Sommer = el verano
der Herbst = el otoño
der Winter = el invierno
der Geburtstag = el cumpleaños | ¡feliz cumpleaños! · Singular und Plural gleich
das Fest / die Party = la fiesta | día de fiesta = Feiertag
der Urlaub / die Ferien = las vacaciones | immer Plural · estar de vacaciones
das Wochenende = el fin de semana | ¡buen fin de semana!
das Frühstück = el desayuno | desayunar = frühstücken
das Mittagessen = el almuerzo | Spanien auch: la comida · almorzar = zu Mittag essen
