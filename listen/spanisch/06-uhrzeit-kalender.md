die Stunde / die Uhrzeit = la hora | ¿qué hora es? = wie spät ist es?
die Minute = el minuto
die Uhr = el reloj | Wanduhr und Armbanduhr
der Tag = el día | männlich trotz -a · buenos días = guten Morgen
die Woche = la semana | el fin de semana = das Wochenende
das Wochenende = el fin de semana | ¡buen fin de semana!
der Monat = el mes | Plural: los meses
das Jahr = el año | ñ wie „nj“ · ¿cuántos años tienes? = wie alt bist du?
das Datum = la fecha | ¿qué fecha es hoy?
das Jahrhundert = el siglo | el siglo XXI = das 21. Jahrhundert
das Mal = la vez | Plural: las veces · a veces = manchmal · otra vez = noch einmal
Montag = el lunes | Wochentage klein und männlich · el lunes = am Montag
Dienstag = el martes
Mittwoch = el miércoles
Donnerstag = el jueves
Freitag = el viernes
Samstag = el sábado
Sonntag = el domingo
Januar = enero | Monate werden klein geschrieben · en enero = im Januar
Februar = febrero
März = marzo
April = abril
Mai = mayo
Juni = junio
Juli = julio
August = agosto
September = septiembre | auch: setiembre
Oktober = octubre
November = noviembre
