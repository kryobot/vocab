# Spanischer Grundwortschatz nach Themen – Liste 39 von 39.
# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

die Situation / die Lage = la situación
die Bedingung / der Zustand = la condición
die Beziehung = la relación
die Wirklichkeit / die Realität = la realidad | en realidad = eigentlich
die Ursache / die Sache = la causa | a causa de = wegen
der Grund (Motiv) = el motivo
die Möglichkeit = la posibilidad
die Gelegenheit / die Chance = la oportunidad
die Notwendigkeit / das Bedürfnis = la necesidad
das Interesse = el interés | Plural: los intereses
der Wert / der Mut = el valor
der Prozess / der Vorgang = el proceso
die Handlung / die Aktion = la acción
die Tätigkeit / die Aktivität = la actividad
die Erfahrung = la experiencia
die Maßnahme / das Maß = la medida | a medida que = je nachdem wie
das Risiko = el riesgo
die Energie = la energía
das Zeichen / das Signal = la señal
das Werk / die Baustelle = la obra | obra de teatro = Theaterstück
der Dienst / die Toilette = el servicio | ¿dónde están los servicios? = wo sind die Toiletten?
