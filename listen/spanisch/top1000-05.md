# Fortsetzung des spanischen Grundwortschatzes (Erklärung in Teil 1).

echt / königlich = real | la familia real = die Königsfamilie
wirklich (Adverb) = realmente | auch: de verdad
vielleicht = quizás | auch: tal vez, a lo mejor
natürlich (selbstverständlich) = por supuesto | auch: claro, desde luego
außerdem = además
trotzdem / jedoch = sin embargo
zusammen = juntos / juntas
dort = allí | LatAm oft: allá · ahí = da (näher)
da (beim Gegenüber) = ahí | ahí está = da ist er/sie/es
draußen = fuera | LatAm: afuera
drinnen = dentro | dentro de una hora = in einer Stunde
oben = arriba | ¡arriba! = hoch!
unten = abajo
vorne / vorwärts = adelante | ¡adelante! = herein! los!
hinten / zurück = atrás | hacia atrás = rückwärts · años atrás = vor Jahren
nah = cerca | cerca de casa = nah am Haus
weit / fern = lejos | lejos de aquí = weit weg von hier
erhalten / bekommen (offiziell) = obtener | obtengo (wie tener)
verlangen / erfordern = exigir | exijo
bedeuten = significar | ¿qué significa …? = was bedeutet …? · auch: querer decir
erreichen / ankommen bei = alcanzar | alcancé
sich erhöhen / zunehmen = aumentar
reduzieren / verringern = reducir | reduzco
vermeiden = evitar
verlassen (Ort) / aufgeben = abandonar
zugeben / zulassen = admitir | admito que … = ich gebe zu, dass …
bestätigen = confirmar
beschreiben = describir | Partizip: descrito
teilen / aufteilen = compartir | compartir piso = in einer WG wohnen
rechnen mit / sich verlassen auf = contar con | cuento contigo = ich zähle auf dich
füllen / ausfüllen = llenar | llenar un formulario
reinigen / putzen = limpiar | limpio / limpia = sauber
waschen = lavar | lavarse las manos = sich die Hände waschen
kochen = cocinar | Wasser kochen = hervir
vorbereiten = preparar
aufstehen = levantarse | me levanto a las siete
aufwachen = despertarse | me despierto
sich anziehen = vestirse | me visto · el vestido = das Kleid
duschen = ducharse | la ducha = die Dusche
sich ausruhen = descansar
anrufen (telefonieren) = telefonear | üblicher: llamar por teléfono
besuchen = visitar | la visita = der Besuch
einladen = invitar | te invito = ich lade dich ein (ich zahle)
tanzen = bailar | el baile = der Tanz
singen = cantar | la canción = das Lied
lachen = reír | río, ríes … · reírse de = lachen über
weinen = llorar
lächeln = sonreír | la sonrisa = das Lächeln
lieben = amar | im Alltag meist: querer · te quiero
hassen = odiar
wünschen = desear | ¡te deseo suerte!
sich Sorgen machen = preocuparse | no te preocupes = keine Sorge
Angst haben = tener miedo | tengo miedo de … = ich habe Angst vor …
sich freuen = alegrarse | me alegro = das freut mich
sich beeilen = darse prisa | ¡date prisa! · LatAm: apurarse
sich irren = equivocarse | me equivoqué = ich habe mich geirrt
merken / bemerken = darse cuenta | me di cuenta de que … = ich habe gemerkt, dass …
heiraten = casarse | casarse con = heiraten (jemanden) · casado/a = verheiratet
geboren werden = nacer | nací en 1985 = ich bin 1985 geboren
wachsen = crecer | crezco
bewegen = mover | muevo · moverse = sich bewegen
umziehen = mudarse | la mudanza = der Umzug
fahren (Auto) = conducir | conduzco · LatAm: manejar
fliegen = volar | vuelo · el vuelo = der Flug
schwimmen = nadar
springen = saltar
werfen = tirar | auch: wegwerfen · tirar la basura
ziehen = tirar de | Türschild: tirar = ziehen, empujar = drücken
drücken / schieben = empujar
fangen / nehmen (Spanien) = coger | in Lateinamerika vulgär – dort agarrar / tomar
festhalten / halten = sostener | sostengo
anhalten / stehen bleiben = parar | sin parar = ununterbrochen
anhalten / festnehmen = detener | detengo (wie tener)
gehören = pertenecer | pertenezco
enthalten = contener | contengo
erfüllen / einhalten = cumplir | cumplir años = Geburtstag haben
schützen = proteger | protejo
retten = salvar
zerbrechen / kaputt machen = romper | Partizip: roto · kaputt = roto / estropeado
reparieren = arreglar | auch: aufräumen, regeln
bauen = construir | construyo
malen = pintar | la pintura = die Malerei, die Farbe
zeichnen = dibujar | el dibujo = die Zeichnung
fotografieren = fotografiar | üblicher: sacar / hacer fotos
die Antwort = la respuesta
die Frage = la pregunta | Thema/Angelegenheit: la cuestión
die Hilfe = la ayuda | ¡ayuda! / ¡socorro! = Hilfe!
die Reise = el viaje | ¡buen viaje! = gute Reise!
der Weg = el camino | en camino = unterwegs
die Wohnung = el piso | LatAm: el departamento · auch: el apartamento
das Stockwerk = la planta | auch: el piso · planta baja = Erdgeschoss
das Fenster = la ventana
die Wand / die Mauer = la pared | Mauer außen: el muro
das Bett = la cama | irse a la cama = ins Bett gehen
der Stuhl = la silla | el sillón = der Sessel
das Sofa = el sofá
die Küche = la cocina | auch: der Herd, das Kochen
das Bad / die Toilette = el baño | ¿dónde está el baño?
der Garten = el jardín
der Schlüssel = la llave | auch: der Wasserhahn
