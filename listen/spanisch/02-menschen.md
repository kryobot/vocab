# Spanischer Grundwortschatz nach Themen – Liste 2 von 39.
# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

ich = yo
du = tú | mit Akzent · tu ohne Akzent = dein
er = él | mit Akzent · el ohne Akzent = der
sie (Singular) = ella | Plural: ellas
Sie (Höflichkeitsform) = usted | Abkürzung Ud. · Verb in der 3. Person: ¿cómo está usted?
wir = nosotros / nosotras
ihr (Plural, Anrede) = vosotros / vosotras | nur in Spanien · LatAm: ustedes
sie (Plural) = ellos / ellas | ellos = männlich oder gemischt
mich / mir = me | me llamo … = ich heiße …
dich / dir = te | te llamo = ich rufe dich an
sich = se | auch „man“: aquí se habla español = hier spricht man Spanisch
uns = nos | nos vemos = wir sehen uns
euch = os | os quiero = ich hab euch lieb (Spanien)
ihm / ihr (indirektes Objekt) = le | Plural: les · le doy el libro = ich gebe ihm/ihr das Buch
ihnen (indirektes Objekt) = les | les escribo = ich schreibe ihnen
ihn / es (direktes Objekt) = lo | lo bueno = das Gute · lo sé = ich weiß es
mein / meine = mi | Plural: mis · mí mit Akzent nach Präposition: para mí
dein / deine = tu | Plural: tus · ohne Akzent (tú = du)
sein / ihr / Ihr (Possessiv) = su | Plural: sus · gilt für él, ella, usted, ellos, ellas
unser / unsere = nuestro / nuestra
euer / eure = vuestro / vuestra | nur in Spanien · LatAm: su
meiner / meine (alleinstehend) = mío / mía | es mío = das gehört mir
deiner / deine (alleinstehend) = tuyo / tuya | es tuyo = das gehört dir
derselbe / selbst = mismo / misma | lo mismo = dasselbe · yo misma = ich selbst
die Person = la persona | immer weiblich, auch für Männer
die Leute = la gente | grammatisch Singular: la gente dice …
der Mann / der Mensch = el hombre | h ist stumm · ¡hombre! = Mensch! (Ausruf)
die Frau = la mujer | auch: Ehefrau · Plural: las mujeres
der Herr = el señor | Sr. García = Herr García
die Dame / Frau (Anrede) = la señora | Sra. García = Frau García
der Junge = el chico | auch: Typ, junger Mann
das Mädchen (junge Frau) = la chica
das Kind = el niño | la niña = das Mädchen · los niños = die Kinder
der Name = el nombre | el apellido = der Nachname
