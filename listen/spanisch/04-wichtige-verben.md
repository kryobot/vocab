# Spanischer Grundwortschatz nach Themen – Liste 4 von 39.
# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

sein (Wesen, Identität, Herkunft) = ser | soy, eres, es, somos, sois, son · ser = was etwas ist, estar = wie/wo es ist
sein (Zustand, Ort) = estar | estoy, estás, está, estamos, estáis, están · estoy cansada = ich bin müde
haben (Hilfsverb) / es gibt = haber | he, has, ha, hemos, habéis, han · hay = es gibt
haben (besitzen) = tener | tengo, tienes, tiene … · tener que = müssen · tengo 30 años = ich bin 30
machen / tun = hacer | hago, haces, hace … · Partizip: hecho · hace frío = es ist kalt
gehen / fahren = ir | voy, vas, va, vamos, vais, van · ir a + Infinitiv = etwas tun werden
weggehen / gehen (fort) = irse | me voy = ich gehe · ¡vete! = geh weg! · ¡vámonos! = los geht’s
können = poder | puedo, puedes, puede, podemos … · el poder = die Macht
sagen = decir | digo, dices, dice … · Partizip: dicho
sehen = ver | veo, ves, ve … · Partizip: visto
wissen = saber | sé, sabes, sabe … · sé nadar = ich kann schwimmen (gelernt)
wollen / lieben = querer | quiero, quieres, quiere … · te quiero = ich hab dich lieb
müssen / sollen / schulden = deber | debes descansar = du solltest dich ausruhen · el deber = die Pflicht
passieren / verbringen / vorbeigehen = pasar | ¿qué pasa? = was ist los?
bleiben / sich verabreden = quedar | quedarse = bleiben · quedamos a las 8 = wir treffen uns um 8
folgen / weitermachen = seguir | sigo, sigues … · sigue lloviendo = es regnet weiter
finden / treffen = encontrar | encuentro · encontrarse con = jemanden treffen
scheinen / aussehen wie = parecer | parezco · me parece bien = finde ich gut
kommen = venir | vengo, vienes, viene … · ¡ven! = komm!
brauchen = necesitar
gefallen / mögen = gustar | me gusta el café = ich mag Kaffee · me gustan los libros (Plural!)
kennen / kennenlernen = conocer | conozco, conoces … · Leute/Orte kennen, Fakten wissen = saber
leben / wohnen = vivir | vivo en Berlín = ich wohne in Berlin
versuchen / behandeln = tratar | tratar de + Infinitiv = versuchen zu · se trata de = es geht um
versuchen (probieren) = intentar | el intento = der Versuch
gewöhnlich tun / pflegen zu = soler | suelo cenar tarde = ich esse meist spät zu Abend
existieren = existir
warten / hoffen = esperar | espero que sí = ich hoffe es
