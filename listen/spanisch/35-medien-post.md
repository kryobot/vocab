# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

das Telefon / das Handy = el teléfono | Handy: el móvil · LatAm: el celular
anrufen (telefonieren) = telefonear | üblicher: llamar por teléfono
markieren / wählen (Nummer) = marcar | marcar un gol = ein Tor schießen
der Computer = el ordenador | LatAm: la computadora
der Fernseher / das Fernsehen = la televisión | kurz: la tele
die Zeitung = el periódico
die Nachricht (Neuigkeit) = la noticia | las noticias = die Nachrichten (TV)
die Nachricht (Mitteilung) = el mensaje | mandar un mensaje = eine Nachricht schicken
die Post / die E-Mail = el correo | correo electrónico = E-Mail · Correos = die Post (Spanien)
der Brief = la carta | auch: die Speisekarte, die Spielkarte
das Foto = la foto | weiblich (von la fotografía)
fotografieren = fotografiar | üblicher: sacar / hacer fotos
das Bild = la imagen | Gemälde = el cuadro
die Information = la información | Plural: las informaciones
die Angabe / die Daten = el dato | los datos = die Daten
das Programm / die Sendung = el programa | männlich trotz -a
das Tagebuch / die Tageszeitung = el diario | a diario = täglich
