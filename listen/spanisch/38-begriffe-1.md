# Spanischer Grundwortschatz nach Themen – Liste 38 von 39.
# Auswahl: die ca. 1000 häufigsten Wörter nach der Häufigkeitsliste von Mark Davies
# („A Frequency Dictionary of Spanish“ – Grundlage der Anki-Decks „Spanish Top 5000
# Vocabulary“ und der Refold-Liste), abgeglichen mit einer Häufigkeitsliste aus
# Film-Untertiteln (OpenSubtitles) und ergänzt um Grundwortschatz (Grüße, Zahlen, Monate).
#
# Rückseite: Nomen mit Artikel (el = männlich, la = weiblich), Adjektive als
# männliche / weibliche Form. Grundlage ist Spanien-Spanisch; lateinamerikanische
# Varianten stehen im Hinweis (LatAm: …).

der Teil = la parte | weiblich · en todas partes = überall
der Fall = el caso | en ese caso = in dem Fall · en todo caso = jedenfalls
die Form / die Art = la forma | de todas formas = jedenfalls
die Art und Weise = la manera | de esta manera = auf diese Weise
der Punkt = el punto | en punto = pünktlich (a las tres en punto)
die Art / der Typ = el tipo | auch: der Kerl · el tipo de cambio = der Wechselkurs
die Art / der Modus = el modo | de todos modos = jedenfalls
die Tatsache / die Tat = el hecho | de hecho = tatsächlich · hecho / hecha = gemacht
das Thema = el tema | männlich trotz -a
die Angelegenheit / die Sache = el asunto
der Gegenstand / das Ziel = el objeto | el objetivo = das Ziel
das Papier / die Rolle = el papel | papel higiénico = Klopapier · jugar un papel = eine Rolle spielen
das Mittel / die Mitte = el medio | los medios = die Medien · en medio de = mitten in
der Bereich / die Fläche = el área | weiblich: las áreas (el wegen betontem a-)
die Basis / die Grundlage = la base | a base de = auf Grundlage von
der Raum / der Platz (Weltraum) = el espacio
der Rest = el resto | los restos = die Überreste
das Detail = el detalle | ¡qué detalle! = wie aufmerksam!
die Gruppe = el grupo
die Ebene / das Niveau = el nivel
das System = el sistema | männlich trotz -a
die Ordnung / der Befehl = el orden / la orden | el orden = Ordnung, Reihenfolge · la orden = Befehl
der Stil = el estilo
eigen = propio / propia | mi propia casa = mein eigenes Haus
einzig / einzigartig = único / única | lo único = das Einzige
allgemein = general | en general / por lo general = im Allgemeinen
natürlich (naturgemäß) = natural | ¡es natural! = das ist normal
persönlich = personal | el personal = das Personal
