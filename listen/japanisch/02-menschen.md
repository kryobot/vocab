# Japanischer Grundwortschatz nach Themen – Liste 2 von 39.
# Auswahl: iKnow „Japanese Core 1000“ (Grundlage der Anki-Decks Core 2k/6k),
# JLPT N5/N4 und wichtige Alltagswörter; Lesungen mit JMdict geprüft.
#
# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

ich = 私 / わたし | sprich: wataschi · sehr förmlich: わたくし
ich (Männer, locker) = 僕 / ぼく | sprich: boku
ich (Männer, salopp) = 俺 / おれ | sprich: ore
wir = 私たち / わたしたち | sprich: wataschitatschi
du / Sie = あなた | sprich: anata · wird oft vermieden – besser Name + さん
du (vertraut) = 君 / きみ | sprich: kimi
er / der Freund (Partner) = 彼 / かれ | sprich: kare
sie / die Freundin (Partnerin) = 彼女 / かのじょ | sprich: kanodscho
sie (Mehrzahl) = 彼ら / かれら | sprich: karera
selbst / man selbst = 自分 / じぶん | sprich: dschibun
Herr … / Frau … (nach dem Namen) = さん | sprich: san · 田中さん = Herr / Frau Tanaka · nie für sich selbst
der Mensch / die Person = 人 / ひと | sprich: hito
die Person (höflich) = 方 / かた | sprich: kata · あの方 = jene Person
der Mensch (als Lebewesen) = 人間 / にんげん | sprich: ningen
alle = みんな | sprich: minna
alle (Anrede) / meine Damen und Herren = 皆さん / みなさん | sprich: minassan
der Name = 名前 / なまえ | sprich: nama-e · お名前は? = Wie heißen Sie?
der Familienname = 名字 / みょうじ | sprich: mjoodschi · steht im Japanischen vor dem Vornamen
der Mann = 男 / おとこ | sprich: otoko · höflicher: 男の人
die Frau = 女 / おんな | sprich: onna · höflicher: 女の人
der Mann (formell) = 男性 / だんせい | sprich: dansee
die Frau (formell) = 女性 / じょせい | sprich: dschossee
der Junge = 男の子 / おとこのこ | sprich: otokonoko
das Mädchen = 女の子 / おんなのこ | sprich: onnanoko
das Kind = 子供 / こども | sprich: kodomo · auch 子ども geschrieben
das Kind (kurz) = 子 / こ | sprich: ko · この子 = dieses Kind
der / die Erwachsene = 大人 / おとな | sprich: otona
das Baby = 赤ちゃん / あかちゃん | sprich: akatschan
der junge Mensch = 若者 / わかもの | sprich: wakamono
der Freund / die Freundin = 友達 / ともだち | sprich: tomodatschi
das Gegenüber / der Partner = 相手 / あいて | sprich: aite · auch: der Gegner (im Spiel)
der Gast / der Kunde = 客 / きゃく | sprich: kjaku · höflich: お客さん, お客様
der Japaner / die Japanerin = 日本人 / にほんじん | sprich: nihondschin
der / die Deutsche = ドイツ人 / ドイツじん | sprich: doitsudschin
der Ausländer / die Ausländerin = 外国人 / がいこくじん | sprich: gaikokudschin · kurz: 外人 (gilt als unhöflich)
viele Leute = 大勢 / おおぜい | sprich: oosee
der / die Reiche = 金持ち / かねもち | sprich: kanemotschi · meist お金持ち
