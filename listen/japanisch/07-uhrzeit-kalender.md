# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

wie viel Uhr = 何時 / なんじ | sprich: nandschi · Uhrzeit: Zahl + 時 (じ) · 四時 = よじ
fünf Minuten = 五分 / ごふん | sprich: gofun · Minuten: Zahl + 分 (ふん / ぷん)
halb (Uhrzeit) = 半 / はん | sprich: han · 二時半 = halb drei
vormittags / a.m. = 午前 / ごぜん | sprich: gosen
nachmittags / p.m. = 午後 / ごご | sprich: gogo
die Uhr = 時計 / とけい | sprich: tokee
der Wecker = 目覚まし時計 / めざましどけい | sprich: mesamaschidokee
der Wochentag = 曜日 / ようび | sprich: joobi · 何曜日 = welcher Wochentag?
der Montag = 月曜日 / げつようび | sprich: getsujoobi · 月 = Mond
der Dienstag = 火曜日 / かようび | sprich: kajoobi · 火 = Feuer
der Mittwoch = 水曜日 / すいようび | sprich: suijoobi · 水 = Wasser
der Donnerstag = 木曜日 / もくようび | sprich: mokujoobi · 木 = Baum, Holz
der Freitag = 金曜日 / きんようび | sprich: kin-joobi · 金 = Gold, Geld
der Samstag = 土曜日 / どようび | sprich: dojoobi · 土 = Erde
der Sonntag = 日曜日 / にちようび | sprich: nitschijoobi · 日 = Sonne
die Woche = 週 / しゅう | sprich: schuu · 一週間 = eine Woche (Dauer)
das Wochenende = 週末 / しゅうまつ | sprich: schuumatsu
der Januar = 一月 / いちがつ | sprich: itschigatsu · Monate: Zahl + 月 (がつ) · Achtung: 四月 しがつ, 七月 しちがつ, 九月 くがつ
ein Monat (Dauer) = 一か月 / いっかげつ | sprich: ik-kagetsu
das Jahr / das Alter = 年 / とし | sprich: toschi · als Zählwort: ねん (2026年)
der Kalender = カレンダー | sprich: karendaa
der Geburtstag = 誕生日 / たんじょうび | sprich: tandschoobi

der 6. / sechs Tage = 六日 / むいか | sprich: muika

der 8. / acht Tage = 八日 / ようか | sprich: jooka
