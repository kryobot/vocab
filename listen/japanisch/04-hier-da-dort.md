# Japanischer Grundwortschatz nach Themen – Liste 4 von 39.
# Auswahl: iKnow „Japanese Core 1000“ (Grundlage der Anki-Decks Core 2k/6k),
# JLPT N5/N4 und wichtige Alltagswörter; Lesungen mit JMdict geprüft.
#
# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)
#
# こ = bei mir, そ = bei dir, あ = weit weg von uns beiden, ど = Frage (→ Liste 03)

das hier (bei mir) = これ | sprich: kore
das da (bei dir) = それ | sprich: sore
das dort drüben = あれ | sprich: are
dieser / diese / dieses … (hier) = この | sprich: kono · この本 = dieses Buch
der / die / das … (da, bei dir) = その | sprich: sono
jener / jene / jenes … (dort drüben) = あの | sprich: ano · auch Füllwort: äh …
hier = ここ | sprich: koko
da (bei dir) = そこ | sprich: soko
dort drüben = あそこ | sprich: assoko
hier / diese Seite (höflich) = こちら | sprich: kotschira · こちらは田中さんです = Das ist Herr Tanaka.
da / Ihre Seite (höflich) = そちら | sprich: sotschira
dort drüben (höflich) = あちら | sprich: atschira
hier(her) (locker) = こっち | sprich: kot-tschi
da(hin) (locker) = そっち | sprich: sot-tschi
dort drüben (locker) = あっち | sprich: at-tschi
so ein … (wie dieses hier) = こんな | sprich: konna
so ein … (wie das da) = そんな | sprich: sonna
so ein … (wie das dort) = あんな | sprich: anna
so / auf diese Weise = こう | sprich: koo
so / genau so = そう | sprich: soo · そうです = stimmt, genau
so (wie dort) / ach = ああ | sprich: aa
so sehr / so viel = そんなに | sprich: sonnani · そんなに高くない = nicht so teuer
ab jetzt / von nun an = これから | sprich: korekara
