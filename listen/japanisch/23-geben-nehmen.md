# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

geben (mir / uns) = くれる | sprich: kureru
bekommen = もらう | sprich: morau
(ver)leihen = 貸す / かす | sprich: kassu
(sich) ausleihen = 借りる / かりる | sprich: kariru
zurückgeben = 返す / かえす | sprich: ka-essu
übergeben / aushändigen = 渡す / わたす | sprich: watassu
schicken = 送る / おくる | sprich: okuru · auch: jemanden (nach Hause) bringen
ankommen (Post) / erreichen = 届く / とどく | sprich: todoku
entgegennehmen = 受け取る / うけとる | sprich: uketoru
mitnehmen (Sachen) = 持って行く / もっていく | sprich: mot-te iku
mitnehmen (Person) = 連れて行く / つれていく | sprich: tsurete iku
mitbringen (Person) = 連れて来る / つれてくる | sprich: tsurete kuru
abholen / empfangen = 迎える / むかえる | sprich: muka-eru · 駅に迎えに行く = am Bahnhof abholen
teilen / aufteilen = 分ける / わける | sprich: wakeru
tragen / transportieren = 運ぶ / はこぶ | sprich: hakobu
sammeln = 集める / あつめる | sprich: atsumeru
sich versammeln = 集まる / あつまる | sprich: atsumaru
suchen = 探す / さがす | sprich: sagassu
finden = 見つける / みつける | sprich: mitsukeru
gefunden werden = 見つかる / みつかる | sprich: mitsukaru
verlieren (etwas) = 無くす / なくす | sprich: nakussu
fallen lassen / verlieren = 落とす / おとす | sprich: otossu
kleben / aufkleben = 貼る / はる | sprich: haru
helfen (mit anpacken) = 手伝う / てつだう | sprich: tetsudau
helfen / retten = 助ける / たすける | sprich: tassukeru
brauchen = 要る / いる | sprich: iru · nicht verwechseln mit いる (da sein)
die Nutzung = 利用 / りよう | sprich: rijoo · 利用する = nutzen
haben wollen = 欲しい / ほしい | sprich: hoschii
