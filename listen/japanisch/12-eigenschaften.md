# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

groß = 大きい / おおきい | sprich: ookii
klein = 小さい / ちいさい | sprich: tschiissai
groß … (vor Nomen) = 大きな / おおきな | sprich: ookina · 大きな家 = ein großes Haus
klein … (vor Nomen) = 小さな / ちいさな | sprich: tschiissana
hoch / teuer = 高い / たかい | sprich: takai
niedrig = 低い / ひくい | sprich: hikui
billig = 安い / やすい | sprich: jassui
lang = 長い / ながい | sprich: nagai
kurz = 短い / みじかい | sprich: midschikai
weit / geräumig = 広い / ひろい | sprich: hiroi
eng / klein (Raum) = 狭い / せまい | sprich: semai
schwer (Gewicht) = 重い / おもい | sprich: omoi
leicht (Gewicht) = 軽い / かるい | sprich: karui
viel / zahlreich = 多い / おおい | sprich: ooi · steht nicht vor Nomen – dann たくさんの
wenig = 少ない / すくない | sprich: sukunai
neu = 新しい / あたらしい | sprich: ataraschii
alt (Dinge) = 古い / ふるい | sprich: furui · nicht für Menschen
jung = 若い / わかい | sprich: wakai
früh = 早い / はやい | sprich: hajai
schnell = 速い / はやい | sprich: hajai · früh = 早い (gleiche Aussprache)
langsam / spät = 遅い / おそい | sprich: ossoi
stark = 強い / つよい | sprich: tsujoi
schwach = 弱い / よわい | sprich: jowai
dick (Buch, Stoff) = 厚い / あつい | sprich: atsui
dünn (Buch, Stoff) / schwach (Geschmack) = 薄い / うすい | sprich: ussui
dick (Gegenstände) = 太い / ふとい | sprich: futoi · 太る = zunehmen (Gewicht)
dünn / schmal = 細い / ほそい | sprich: hossoi
fein / detailliert / kleinlich = 細かい / こまかい | sprich: komakai
tief = 深い / ふかい | sprich: fukai
rund = 丸い / まるい | sprich: marui
hart / fest = 固い / かたい | sprich: katai · auch 硬い
weich = 柔らかい / やわらかい | sprich: jawarakai
die Form = 形 / かたち | sprich: katatschi
die Größe = 大きさ / おおきさ | sprich: ookissa · -さ macht aus Adjektiven Nomen: 高さ = Höhe, 長さ = Länge
