# Japanischer Grundwortschatz nach Themen – Liste 3 von 39.
# Auswahl: iKnow „Japanese Core 1000“ (Grundlage der Anki-Decks Core 2k/6k),
# JLPT N5/N4 und wichtige Alltagswörter; Lesungen mit JMdict geprüft.
#
# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

was = 何 / なに | sprich: nani · vor d-, t-, n-Lauten: なん (何ですか)
wer = 誰 / だれ | sprich: dare
wer (höflich) = どなた | sprich: donata
wo = どこ | sprich: doko
wann = いつ | sprich: itsu
ungefähr wann = いつ頃 / いつごろ | sprich: itsugoro
wie = どう | sprich: doo · どうですか = Wie ist es?
wie (höflich) = いかが | sprich: ikaga · コーヒーはいかがですか = Möchten Sie Kaffee?
warum = どうして | sprich: dooschite
warum (eher schriftlich) = なぜ | sprich: nase
wie viel (kostet) = いくら | sprich: ikura
wie viele / wie alt = いくつ | sprich: ikutsu
welche(r/s) (von mehreren) = どれ | sprich: dore
welche(r/s) … (vor Nomen) = どの | sprich: dono · どの本 = welches Buch
was für ein … = どんな | sprich: donna
welche(r) von beiden / wo (höflich) = どちら | sprich: dotschira
welche(r) von beiden (locker) = どっち | sprich: dot-tschi
etwas = 何か / なにか | sprich: nanika
jemand = 誰か / だれか | sprich: dareka
irgendwo = どこか | sprich: dokoka
irgendwann = いつか | sprich: itsuka
nichts (mit Verneinung) = 何も / なにも | sprich: nanimo
niemand (mit Verneinung) = 誰も / だれも | sprich: daremo
