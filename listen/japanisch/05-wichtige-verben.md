# Japanischer Grundwortschatz nach Themen – Liste 5 von 39.
# Auswahl: iKnow „Japanese Core 1000“ (Grundlage der Anki-Decks Core 2k/6k),

#
# Rückseite: das Wort so, wie man es normalerweise schreibt. Mit Kanji folgt nach
# dem „/“ die Lesung in Hiragana (statt Furigana); Wörter, die man in Kana schreibt,
# stehen nur in Hiragana, Fremdwörter nur in Katakana.
# sprich = deutsche Lautschrift: sch, tsch, dsch, j wie im Deutschen · s am Wortanfang scharf
# wie in „Bus“, zwischen Vokalen weich; ss = scharf · ds = stimmhaftes „ds“ · aa/ii/uu/ee/oo = lang ·
# w wie im Englischen · r kurz getippt · Bindestrich = Silbengrenze bzw. kleine Pause (kit-te, ka-eru)

machen / tun = する | sprich: suru · Nomen + する bildet viele Verben: 勉強する = lernen
werden = なる | sprich: naru
es gibt / vorhanden sein (Dinge) = ある | sprich: aru
es gibt / da sein (Lebewesen) = いる | sprich: iru
nicht vorhanden sein / es gibt nicht = ない | sprich: nai · Verneinung von ある · Kanji: 無い
machen / tun (locker) = やる | sprich: jaru
können / fertig werden = できる | sprich: dekiru · Kanji: 出来る
gehen / fahren (hin) = 行く / いく | sprich: iku
kommen = 来る / くる | sprich: kuru
zurückkehren / nach Hause gehen = 帰る / かえる | sprich: ka-eru
sehen / anschauen = 見る / みる | sprich: miru
sagen = 言う / いう | sprich: iu
denken / meinen = 思う / おもう | sprich: omou
verstehen = 分かる / わかる | sprich: wakaru · oft in Kana: わかる
wissen / kennen = 知る / しる | sprich: schiru · 知っています = ich weiß
hören / fragen = 聞く / きく | sprich: kiku
sprechen / erzählen = 話す / はなす | sprich: hanassu
benutzen = 使う / つかう | sprich: tsukau
machen / herstellen = 作る / つくる | sprich: tsukuru · auch: kochen (料理を作る)
haben / halten / tragen = 持つ / もつ | sprich: motsu
nehmen = 取る / とる | sprich: toru
warten = 待つ / まつ | sprich: matsu
treffen = 会う / あう | sprich: au · 友達に会う = einen Freund treffen
hinausgehen / herauskommen = 出る / でる | sprich: deru
hineingehen / eintreten = 入る / はいる | sprich: hairu
wohnen = 住む / すむ | sprich: sumu · 東京に住んでいます = ich wohne in Tokio
arbeiten = 働く / はたらく | sprich: hataraku
anfangen (etwas) = 始める / はじめる | sprich: hadschimeru
anfangen / beginnen (von selbst) = 始まる / はじまる | sprich: hadschimaru
enden / zu Ende gehen = 終わる / おわる | sprich: owaru
